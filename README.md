# Spin Wheel 499

Prosta strona mobilna typu spin wheel przygotowana pod GitHub Pages.

## Pliki
- `index.html`
- `style.css`
- `script.js`

## Uruchomienie na GitHub Pages
1. Utwórz nowe repozytorium na GitHubie.
2. Wgraj wszystkie trzy pliki do głównego katalogu repozytorium.
3. Wejdź w **Settings → Pages**.
4. W sekcji **Build and deployment** wybierz:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Zapisz ustawienia.

## Ważne
Koło zawiera dokładnie 19 pól.
Wynik 499 zł jest celowo ustawiony jako gwarantowany i opisany na stronie jako nielosowy.
